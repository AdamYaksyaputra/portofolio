# 02: Project Details (RTCC-O)

## RTCC-O Template

```markdown
## R — Role
Siapa AI dalam konteks ini?

Senior front-end developer dengan keahlian HTML semantik, CSS modern, dan pengalaman membuat portfolio untuk fresh graduate

---

## T — Task
Apa tugas utama project ini?

Buat portfolio website satu halaman (single page) untuk fresh graduate IT yang menampilkan profil, skills, project, dan contact secara profesional namun tetap modern.

---

## C — Context
Tech stack, constraints, standards:

- Tech: HTML5 + CSS3 (tanpa framework)
- Approach: Mobile-first design
- Audience: Recruiter HR dan Tech Lead (startup)
- Identity: Modern & approachable developer
- Goal: Mudah dibaca, cepat dipahami, dan menarik dalam 30 detik pertama

---

## C — Constraints
Yang TIDAK boleh:
- [ZERO non-semantic div]
- Menggunakan framework (Bootstrap, Tailwind, dll)
- Desain terlalu kompleks atau berat
- Copy paste tanpa penjelasan

Yang WAJIB:
- Menggunakan semantic HTML5 (header, nav, main, section, footer)
- Responsive (mobile-first)
- Clean dan readable code
- Layout sederhana tapi rapi
- Bisa dijelaskan ke recruiter

---

## O — Output
Format yang diinginkan:

- Format: HTML dan CSS terpisah (index.html + style.css)
- Struktur code rapi dan terorganisir
- Disertai komentar singkat pada bagian penting
- Tidak terlalu verbose, fokus ke implementasi

---
